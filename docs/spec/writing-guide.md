# 仕様の記述ルール

## 新しい画面

次の書式を`screens.md`へ追加します。

```markdown
## SCR-番号: 画面名

- 状態: 未設計
- サイズ: 480 × 272 px
- 用途: この画面の目的

### 表示

- 表示する情報

### ボタン

- ボタン名

### 操作

- 入力: 結果
```

## 新しいボタン

最初に`buttons.md`の一覧表へ追加し、条件分岐がある場合だけ詳細を書きます。

```markdown
## BTN-番号: ボタン名

### 条件

- 実行できる条件

### 実行

- 行う処理

### 成功

- 成功時の画面表示や状態

### 失敗

- 失敗時の画面表示や状態
```

## 書き方の原則

- 「いい感じに表示する」のような曖昧な表現を避ける
- ボタンを押す前の条件、行う処理、処理後の状態を分ける
- 画面名には`SCR-番号`、ボタンには`BTN-番号`を付ける
- 座標、色、余白などの詳細はPenpotを正とする
- 未決定事項を推測で埋めず、`未設計`または`要決定`と書く
