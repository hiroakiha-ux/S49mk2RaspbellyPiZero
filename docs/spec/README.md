# SEQTRAK Controller 仕様書

このディレクトリは、S49 MK2 LCD上で動作する画面と操作の仕様を管理します。

## 文書一覧

- [画面一覧](screens.md)
- [ボタン一覧](buttons.md)
- [画面・ボタン操作フロー](ui-flow.md)
- [記述ルール](writing-guide.md)

## 仕様の分担

- Penpot: 画面の見た目、寸法、色、配置
- この仕様書: 画面遷移、ボタン、操作、条件、結果
- C++: 仕様を実際に動かす処理

## 状態の表記

- `実装済み`: 現在のプログラムで動作する
- `設計済み`: Penpotには存在するが、プログラムには未実装
- `未設計`: 名前または目的だけが決まっている

仕様を変更するときは、最初にこの文書を更新し、その後Penpotとプログラムへ反映します。
